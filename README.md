# COVID-19 Data Analysis and Network Visualization

## Overview
This project analyzes COVID-19 data in India using Python and generates visualizations to explore case trends, active cases, state-wise statistics, and network relationships.

## Features
- COVID-19 confirmed cases over time
- Active case analysis
- State-wise case comparison
- Heatmap visualization
- COVID-19 network visualization
- Centrality analysis
- Comparison of centrality measures with COVID-19 cases

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- NetworkX
- Scikit-learn

## Installation and Execution

1. Install Python 3.
2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the script from the project directory:

   ```bash
   python covid_graph.py
   ```

The script reads `complete.csv` and generates visualizations in the `outputs/` directory.

## Dataset
The project uses the `complete.csv` dataset included in this repository. Refer to the original dataset source for provenance and usage conditions.

## Outputs
The `outputs/` directory contains the visualizations generated by the project.

## Disclaimer
This project is intended for educational and data-analysis purposes. Its visualizations should not be interpreted as medical advice.
